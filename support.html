Help & Support

Questions about mpvCOLOR? Email micropixelversecoloring@gmail.com. Include your device model, operating system, app version and a short description of the issue. Never send account passwords.

Coloring and mini games

Use the in-game tutorials to learn each activity. Available content depends on the version installed on your device.


Backup and restore

Open Settings and the game-data controls. iOS uses iCloud; Android uses Google Play Games where configured. Connect to the internet and use the same platform account that created the backup. Back up before changing devices. Restoring replaces current local progress. There is no iOS–Android backup transfer.


Delete a cloud backup

In Settings, open the game-data / backup controls and choose the delete-backup action, then confirm. This clears only the selected platform’s cloud backup. Existing progress on devices remains. Uninstalling alone does not delete cloud backups. See the data deletion explanation for details. Contact support if you cannot access the controls.


Advertisements and rewards

Ads require an internet connection and may be unavailable at times. If an offered reward is missing, tell us which screen you used and what happened.


Privacy questions
